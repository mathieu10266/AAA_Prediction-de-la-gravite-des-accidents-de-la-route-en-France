# AAA_Prediction-de-la-gravite-des-accidents-de-la-route-en-France
L'objectif de ce projet est de développer un modèle d'apprentissage automatique supervisé capable de prédire la gravité d'un accident de la route à partir de ses caractéristiques (conditions atmosphériques, caractéristiques du lieu, profil de la route, types de véhicules impliqués, profils des usagers).
